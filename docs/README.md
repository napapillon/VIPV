# Documents

| File | Content |
|---|---|
| `Internship_Report_Papillon.pdf` | Internship report: context, methods, results and appendices. Appendix C describes the preparation chains and the file-naming system used by the scripts; appendices D and E list the CLC and COS2023 classes. |
| `nomenclatures/CLC_Classification.xlsx` | The 44 CORINE Land Cover 2018 classes (levels 1-3) with the urban/rural grouping used in this work. Source table of `code/common/clc_mapping.py`. |
| `nomenclatures/COS_Classification_EN.xlsx` | The 93 COS2023 level-4 classes with levels 1-3, in English. The translation was made for this project from the official Portuguese nomenclature of the DGT. Source table of `code/common/cos23_mapping.py`. |
| `nomenclatures/COS_Classification_PT.xlsx` | The same table with the original Portuguese labels of the DGT. |

Official references for the two nomenclatures:
- CORINE Land Cover, EEA technical guidelines (legend, part 2):
  <https://www.eea.europa.eu/en/analysis/publications/cor0-part2>
- COS2023, technical specifications and nomenclature, Direção-Geral do
  Território: <https://www.dgterritorio.gov.pt/> (documents published in
  Portuguese).
